ترسم مشهد مسجد عند الشروق/الغروب بالكامل بالكود (بلا صورة خارجية) حين
لا يجد ملف صورة هنا.

لاستعمال صورة حقيقية بدل الرسمة، أضف ملفًا باسم:

    arch_hero.jpg

للشاشات عالية الكثافة. التفاصيل الكاملة (توزيع المحتوى داخل الصورة،
الجزء الذي يُغطّى بتدرّج داكن، إلخ) موثّقة أعلى ملف
`lib/widgets/prayer_arch_hero.dart`.
